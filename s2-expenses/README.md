# s2-expenses

Séance 02 - Offline Expense Tracker (IAM2, React Native avec Expo)

## Auteur

Shahd Bargougui

## Ce qui est réalisé

- Base SQLite ouverte avec SQLiteProvider, migration versionnée avec PRAGMA user_version
- Dépôt expenseRepo et hooks useExpenses, useExpense, useExpenseActions
- Ajout, modification et suppression d'une dépense avec un formulaire contrôlé
- Filtre par catégorie et total avec SUM()
- Insertion de trois exemples dans une transaction
- Défi (migration v2, colonne note) : non fait
